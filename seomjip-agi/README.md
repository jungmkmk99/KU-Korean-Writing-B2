# 섬집 아기 받아쓰기

한국어 학습자를 위한 노래 「섬집 아기」 가사 빈칸 쓰기 활동 앱입니다.

- 도입: 그림을 보고 이야기하기
- 쓰기: 노래를 들으며 두 줄씩 빈칸 채우기 (다음/이전 버튼)
- 결과: 정답 확인, 별점, 틀린 것 다시 쓰기, 전체 가사 보기

## GitHub Pages로 올리기

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더의 파일(`index.html`, `images/intro.png`, `README.md`)을 그대로 업로드합니다.
   (**Add file → Upload files**에서 폴더째 끌어다 놓으면 됩니다.)
3. 저장소의 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 선택하고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있습니다.

## 고치는 방법

- **노래 링크**: `index.html`의 `SONG_URL` 값을 원하는 유튜브 영상 주소로 바꾸세요.
- **빈칸**: `LINES` 배열에서 `b("정답")` 부분이 빈칸입니다. 일반 글자는 그냥 문자열로 쓰면 됩니다.
